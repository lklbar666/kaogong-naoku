# 第五章：逻辑判断·翻译推理

## 核心思想

把自然语言翻译为逻辑表达式，按逻辑规则推理。核心是熟记翻译规则和推理规则。

## 一、翻译规则

### 1. 充分条件（前推后）

**典型关联词**：
- 如果……那么……
- 只要……就……
- 若……则……
- 所有……都……
- 为了……一定……
- A是B的充分条件

**翻译**：A → B（前半句推后后半句）

### 2. 必要条件（后推前）

**典型关联词**：
- 只有……才……
- 不……不……
- 除非……否则不……
- A是B必不可少的/基础/前提
- A是B的必要条件

**翻译**：B → A（后半句推前半句）

### 3. 特殊关联词

| 表述 | 翻译 |
|---|---|
| 除非A否则B | ¬A→B |
| A必须B | A→B |
| A离不开B | A→B |
| 有的A是B | 有的A→B |
| 有的A不是B | 有的A→¬B |

### 4. 且关系（且）

**关联词**：和、并且、同时、既……又……、不仅……而且……
**翻译**：A且B
**性质**：全真才真，一假则假

### 5. 或关系（或）

**关联词**：或者……或者……、至少一个、不都是
**翻译**：A或B
**性质**：一真则真，全假才假
**注意**："至少一个"是或，"要么要么"是二选一

## 二、推理规则

### 1. 逆否规则（最核心）

- **原命题**：A→B
- **逆否命题**：¬B→¬A
- **口诀**：肯前必肯后，否后必否前
- **错误**：否前推不出，肯后推不出

**示例**：
- 如果下雨（A），地就湿（B）：A→B
- 地没湿（¬B）→ 没下雨（¬A）✓
- 没下雨（¬A）→ 地不湿？推不出（可能洒水）
- 地湿了（B）→ 下雨了？推不出（可能洒水）

### 2. 传递规则

- A→B，B→C，可得 A→B→C
- 前提：相同的B位置一致

### 3. 摩根公式（且或转换）

- ¬(A且B) = ¬A或¬B
- ¬(A或B) = ¬A且¬B
- 口诀：去括号，负号进去，且变或、或变且

### 4. 或关系推理

- A或B，否定一个必肯定另一个
- A或B，¬A→B
- 但肯定一个推不出另一个

### 5. 有的（存在量词）推理

- 有的A是B → 有的B是A
- 有的A→B，B→C，可得有的A→C
- 注意：有的不能逆否
- 有的A是B不能推出有的A不是B

## 三、真假推理

### 矛盾关系（必一真一假）

| 类型 | 矛盾 |
|---|---|
| A与非A | 单称命题 |
| 所有都 vs 有的不 | 全称与特称 |
| 所有都不 vs 有的是 | 全称与特称 |
| A→B 与 A且¬B | 充分条件 |
| A且B 与 ¬A或¬B | 摩根 |
| A或B 与 ¬A且¬B | 摩根 |

### 反对关系

- **上反对**：所有都vs所有都不，必有一假，可以同假
- **下反对**：有的是vs有的不是，必有一真，可以同真

### 真假推理解题步骤

1. 找矛盾（或反对）关系
2. 绕开矛盾，判断其他命题真假
3. 回到矛盾，确定具体真假

## 四、分析推理（排列组合）

### 常用方法

**1. 排除法**
- 选项信息充分时优先用
- 读条件，排除不符合的选项

**2. 最大信息法**
- 从出现次数最多的信息切入
- 逐步推理

**3. 确定信息法**
- 从确定的条件开始
- 优先找最明确的信息

**4. 假设法**
- 假设某条件成立，验证
- 出现矛盾则假设不成立

**5. 列表法**
- 人物、对象、条件多维时
- 画表格辅助

## 五、日常结论

### 解题原则
- 可以推出：基于题干能合理推出
- 不选：无中生有、偷换概念、过度推断
- 优选：可能、有的、有时等温和表述
- 慎选：必须、一定、所有、最等绝对词

### 常见错误
- 逻辑错误（因果倒置、充分必要混淆）
- 无中生有（题干没提）
- 偷换概念（换了主体或概念）
- 夸大范围（个体推整体）

## 母题抽象

🧩 **翻译推理母题**：当题干出现"如果……就""只有……才"等关联词时，先翻译为逻辑表达式，再用逆否规则（否后必否前）推理。

🧩 **真假推理母题**：当题目说"只有一人说真话/假话"时，先找矛盾关系，再绕开判断其他。

## 关键 takeaway

1. 熟记翻译规则：如果就前推后，只有才后推前
2. 逆否规则是核心：肯前必肯后，否后必否前
3. 摩根公式：去括号负号进去，且或互换
4. 真假推理先找矛盾
5. 分析推理优先排除法
