# 第六章：图形推理·类比推理·定义判断

## 一、图形推理

### 规律体系总览

| 大类 | 具体规律 |
|---|---|
| **位置规律** | 平移、旋转、翻转 |
| **样式规律** | 遍历、加减同异、黑白运算 |
| **数量规律** | 点、线、面、素、角 |
| **属性规律** | 对称性、曲直性、开闭性 |
| **空间重构** | 六面体、三视图、截面 |
| **平面拼合** | 平行等长相消 |
| **功能元素** | 黑点、箭头标记 |

### 1. 位置规律
- **特征**：元素组成相同，位置变化
- **平移**：方向（上下左右/对角线）、步数（恒定/递增）
- **旋转**：方向（顺/逆时针）、角度（45/90/180）
- **翻转**：左右翻转、上下翻转

### 2. 样式规律
- **遍历**：元素组成相似，缺什么补什么
- **加减同异**：
  - 相加：两图叠加
  - 求同：保留相同部分
  - 求异：保留不同部分
- **黑白运算**：黑+白、白+黑、白+白、黑+黑（按组内规则）

### 3. 数量规律
- **点**：交点、切点、曲直交点（线条交叉明显）
- **线**：直线数、曲线数、笔画数（单线条明显）
- **面**：封闭区域数（窟窿多）
- **素**：元素个数、种类、部分数（独立小元素）
- **角**：直角、锐角、钝角（锯齿图形）

### 4. 属性规律
- **对称性**：
  - 轴对称（轴的方向、数量）
  - 中心对称
  - 轴+中心对称
- **曲直性**：全曲、全直、曲+直
- **开闭性**：全开放、全封闭

### 5. 空间重构
- **相对面**：不相邻（同行或同列隔一个）
- **相邻面**：公共边、公共点、画边法
- **相对位置**：箭头法、时针法

### 6. 平面拼合
- **平行等长相消**：平行且等长的边消去
- 只能上下左右平移，不能旋转翻转

### 图形推理解题思维

1. 元素组成相同 → 看位置
2. 元素组成相似 → 看样式
3. 元素组成不同 → 先看属性，再看数量
4. 空间类 → 用方法，不靠空间想象

## 二、类比推理

### 关系体系

#### 1. 语义关系
- **近义关系**：意思相近
- **反义关系**：意思相反
- **比喻义、象征义**：词语的比喻象征

#### 2. 逻辑关系

| 关系 | 说明 |
|---|---|
| **全同关系** | 同一事物不同名称 |
| **并列关系** | 矛盾（非A即B）、反对（有第三种） |
| **包容关系** | 种属（A是B的一种）、组成（A是B的部分） |
| **交叉关系** | 有的A是B，有的A不是B |
| **对应关系** | 功能、材料、工艺、因果、时间、职业、地点 |

#### 3. 语法关系
- 主谓关系
- 动宾关系
- 主宾关系
- 偏正关系

### 二级辨析
- 一级关系相同时，看二级：
  - 词性（名/动/形）
  - 感情色彩（褒/贬/中性）
  - 程度（递进/递减）
  - 范畴（具体/抽象）
  - 必然/或然

### 类比解题步骤
1. 先看一级关系
2. 一级相同看二级辨析
3. 造句法辅助
4. 词序一致原则

## 三、定义判断

### 核心方法：要件分析法

### 1. 找关键要件
- **主体**：动作的发出者（谁做）
- **客体**：动作的对象（对谁做）
- **方式**：怎么做（通过……方式）
- **目的**：为了什么（以……为目的）
- **原因**：因为什么
- **结果**：导致什么
- **条件**：在什么情况下

### 2. 解题步骤
1. 看提问：选是还是选非，单定义还是多定义
2. 读定义：标记关键要件
3. 辨析选项：
   - 要件逐一比对
   - 明显不符合的排除
   - 不确定的保留
4. 选最优：要件匹配最多的

### 3. 多定义
- 重点看问的那个定义
- 其他定义用于干扰或对比

### 4. 解题技巧
- 关键词定位：专有名词、核心概念
- 选项反推：选项之间找差异
- 同构选项：结构相似的一起排除
- 选非题：找最明显不符合的

### 常见错误
- 要件遗漏（没注意到某条件）
- 主体偷换（换了行为主体）
- 过度解读（加了定义里没有的内容）
- 常识干扰（按自己理解而非定义）

## 母题抽象

🧩 **图形推理母题**：先看元素组成，相同看位置，相似看样式，不同看属性和数量。

🧩 **类比推理母题**：先判断一级关系（语义/逻辑/语法），一级相同看二级辨析（词性、感情色彩、程度）。

🧩 **定义判断母题**：提取主体、客体、方式、目的、条件等要件，逐一比对选项，选匹配度最高的。

## 关键 takeaway

1. 图形推理按"相同→位置，相似→样式，不同→属性/数量"的顺序
2. 类比推理先一级后二级
3. 定义判断抓要件，不加入主观理解
4. 图形规律要系统刷题培养敏感度
5. 定义判断正确率要求90%以上，是必拿分模块
