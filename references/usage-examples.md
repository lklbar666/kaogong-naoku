# 使用示例

```plaintext
=== 示例1：解一道基期量计算题 ===

用户：2023年某省GDP为12.5万亿元，同比增长5.8%，问2022年该省GDP约为多少？

Skill执行（五步标注）：
1. 问法模型：题干时间2023年，求2022年（上年），给现期值和增长率 → 基期量计算
2. 推理链：
   - 第1步：定位现期值12.5万亿元，增长率5.8%
   - 第2步：公式 基期=现期÷(1+增长率)
   - 第3步：代入 12.5÷1.058
3. 最快解法⚡：
   - 增长率5.8%接近5%，可化除为乘：12.5×(1−5.8%)≈12.5×0.942≈11.78
   - 或截位直除：12.5÷1.06≈11.79
   - 答案约11.8万亿元
4. 易错点⚠：
   - 误乘：12.5×(1+5.8%)≈13.2（这是现期算未来，方向反了）
   - 直接减：12.5−0.058×12.5≈11.78（恰好接近，但这是增长量近似）
5. 母题抽象🧩：当题干出现"上年约为"且给现期+增长率时，用现期÷(1+r)，r≤5%可化除为乘。


=== 示例2：增长量百化分 ===

用户：某企业2024年营收500亿元，同比增长25%，问比上年增加了多少亿元？

Skill执行：
1. 问法模型：问"增加多少"，给现期值+增长率 → 增长量计算
2. 推理链：增长量=500÷(1+25%)×25%=500÷1.25×0.25=100
3. 最快解法⚡：百化分，25%=1/4，n=4，增长量=现期÷(n+1)=500÷5=100亿元
4. 易错点⚠：直接500×25%=125（这是基期×增长率才对，现期不能直接乘）
5. 母题抽象🧩：增长率r=1/n时，增长量=现期÷(n+1)。


=== 示例3：因果倒置削弱 ===

用户：研究发现，经常喝咖啡的人患心脏病概率更高，因此喝咖啡会导致心脏病。哪个最能削弱？

Skill执行：
1. 找论点：喝咖啡导致心脏病
2. 找论据：喝咖啡的人心脏病概率高（相关性）
3. 预判：因果论点+相关性论据 → 因果倒置最强
4. 选项分析：
   - A. 心脏病早期症状让人更想喝咖啡（因果倒置）✓
   - B. 咖啡含有某种物质（可能加强或无关）
   - C. 有些人喝咖啡没心脏病（反例，弱）
   - D. 压力大也会导致心脏病（他因，中等）
5. 结论：选A，因果倒置最强
6. 母题🧩：相关性推因果，优先找"结果导致原因"的因果倒置。


=== 示例4：翻译推理 ===

用户：只有年满18周岁，才有选举权。某人有选举权，能推出什么？

Skill执行：
1. 翻译："只有……才"后推前：选举权→年满18岁
2. 已知：有选举权（肯前）
3. 推理：肯前必肯后 → 年满18岁
4. 答案：该人一定年满18周岁
5. 反向验证：如果不满18岁（否后）→ 没有选举权（否前），即否后必否前
6. 母题🧩："只有才"后推前，肯前推肯后，否后推否前。


=== 示例5：图形推理规律判断 ===

用户：一组图形，每个图都是轴对称图形，轴的方向依次旋转45度，下一个应该是？

Skill执行：
1. 元素组成不同，先看属性
2. 都是轴对称 → 属性规律-对称性
3. 轴的方向在变化（旋转）
4. 结合位置规律：对称轴每次顺时针转45度
5. 下一个轴的方向按规律推出
6. 母题🧩：图形组成不同先看属性，对称性关注轴的方向和数量，轴本身可以旋转。


=== 示例6：错题诊断 ===

用户：这道题我选了B，正确答案是C，帮我看看为什么错。（题目：求2022年比重，材料给2023年数据）

Skill执行：
1. 诊断：不看答案重做
2. 题型识别：求"上年比重" → 基期比重题
3. 分析错因：
   - 如果直接用现期部分÷现期整体 → 算的是现期比重，不是基期
   - 基期比重需要乘(1+b)/(1+a)
4. 错误类型：知识盲区（不知道基期比重公式）
5. 回到考点ch02：学习基期比重公式
6. 巩固：找3道基期比重题专项练习
7. 母题🧩：求上年比重，不能只算现期A/B，还要乘(1+b)/(1+a)。


=== 示例7：复习规划 ===

用户：我还有一个月考试，资料分析正确率只有60%，怎么提升？

Skill执行：
1. 诊断：正确率60%说明基础方法有漏洞
2. 四周计划：
   - 第1周：系统过一遍增长类考点（占比最大），每道题做五步标注
   - 第2周：比重、平均数、倍数专项，重点练速算（百化分背熟）
   - 第3周：限时训练，每篇6分钟，重点练速度和陷阱识别
   - 第4周：错题复盘+模拟，保持手感
3. 每日安排：
   - 2篇资料分析（限时12分钟）
   - 错题深度标注
   - 速算练习10分钟
4. 目标：正确率提升到80%+
5. 关键：不追求刷题数量，每道题做深度标注
```
