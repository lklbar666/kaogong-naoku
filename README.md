# 考公脑库 - 行测真题深度标注 Skill

基于 ERRRC/kaogongzhentizhengliu（866星）汉化改编的考公辅导Skill。将2016-2026年国考/省考/联考11,000+道行测真题的深度标注方法论，转化为AI可复用的解题能力。

## 核心特点

- **五步深度标注法**：问法模型→推理链→最快解法→易错点→母题抽象
- **按考点重组**：不按年份刷题，按考点横向对比不同考法
- **覆盖两大模块**：资料分析（7大类）+ 判断推理（5大类）
- **速算技巧体系**：截位直除、百化分、化除为乘、差分法
- **母题抽象**：做一道会一类，从具体题目提炼通用模式

## 覆盖范围

### 资料分析（3569题）
增长、比重、综合、平均数、其他、倍数、基期计算

### 判断推理（7713题）
逻辑判断、图形推理、类比推理、定义判断、科学推理

## 快速开始

1. 贴出题目，自动按五步框架深度讲解
2. 或指定考点学习（如"基期量计算怎么解"）
3. 错题可诊断错因并关联考点
4. 可制定复习计划
