# 第七章：深度标注方法论与学习体系

## 核心思想

本Skill的核心不仅是给答案，而是教会一套"如何深度学习真题"的方法。从一道题提炼出一类题的解法。

## 一、为什么要做深度标注

### 传统刷题的问题
- 只记答案，不理解为什么
- 错题反复错
- 做了很多题但提分慢
- 无法识别题目变形

### 深度标注的价值
- 理解推理过程，而非记答案
- 提炼母题，识别变形
- 系统总结陷阱，避免重复犯错
- 横向对比，理解考点本质

## 二、五步标注法详解

### 第1步：问法模型
**要回答的问题**：
- 这道题在问什么？
- 时间关系是什么？（求过去/现在/未来）
- 看到哪些关键词能判定题型？

**标注方法**：
- 圈出题干关键时间词
- 标记题型特征词
- 用一句话概括题型

### 第2步：推理链
**要回答的问题**：
- 第一步做什么？
- 数据从材料哪里来？
- 每一步的逻辑是什么？
- 有没有跳步？

**标注方法**：
- 分步骤列出，编号
- 每步标注数据出处
- 写出完整公式
- 不跳步、不省略

### 第3步：最快解法
**要回答的问题**：
- 考场上最快怎么算？
- 能不能用速算技巧？
- 有没有更巧妙的思路？

**标注方法**：
- 标注⚡
- 给出至少2种解法
- 说明推荐理由
- 记录估算结果

### 第4步：易错点
**要回答的问题**：
- 这道题容易在哪出错？
- 错误选项为什么存在？
- 自己曾经错过什么？

**标注方法**：
- 标注⚠
- 逐个分析错误选项
- 关联到同类陷阱
- 记录识别方法

### 第5步：母题抽象
**要回答的问题**：
- 这道题的通用模式是什么？
- 换个数字还会做吗？
- 什么特征下用这个方法？

**标注方法**：
- 标注🧩
- 用"当……特征时，用……方法"句式
- 不出现具体数字
- 列出同类特征词

## 三、错题复盘方法

### 错题分类

| 错误类型 | 特征 | 应对 |
|---|---|---|
| **知识盲区** | 不知道考点/方法 | 回到考点学习 |
| **方法不熟** | 知道但不会用 | 专项训练 |
| **计算失误** | 思路对但算错 | 速算训练 |
| **审题错误** | 看错时间/单位/主体 | 标记关键信息 |
| **陷阱入坑** | 被干扰项迷惑 | 总结陷阱 |
| **时间不够** | 会做但来不及 | 限时训练 |

### 错题复盘四步
1. **不看答案重做**：确认是真不会还是粗心
2. **标注错因**：按上表分类
3. **回到考点**：复习相关方法
4. **找同类题**：做3-5道同类题巩固

### 错题记录模板
- 题目来源（地区/年份/题号）
- 我的答案 vs 正确答案
- 错误类型
- 错误原因分析
- 对应考点
- 复习后的新理解

## 四、考点学习方法

### 从考点出发的学习路径
1. 先看考点核心立场（母题抽象）
2. 做2-3道典型例题
3. 横向对比不同考法
4. 总结变形和陷阱
5. 限时刷题巩固

### 为什么按考点学
- 同一考点反复出现
- 理解一个考点=会一类题
- 便于发现薄弱点
- 比按年份刷题效率高

## 五、复习节奏建议

### 阶段一：基础学习（4-6周）
- 系统学习各考点方法
- 不追求速度，理解为主
- 每道题做深度标注
- 目标：掌握所有考点

### 阶段二：专项提升（3-4周）
- 按模块刷题
- 重点突破薄弱点
- 训练速算技巧
- 目标：正确率70%+

### 阶段三：限时训练（2-3周）
- 整套限时做题
- 训练时间分配
- 模拟考场环境
- 目标：资料分析80%+，判断推理85%+

### 阶段四：冲刺复盘（1-2周）
- 回顾错题和笔记
- 保持做题手感
- 查漏补缺
- 不做新题难题

## 六、时间分配建议

### 行测整体（参考）
- 资料分析：25-30分钟（4篇20题）
- 判断推理：30-35分钟
- 言语理解：30-35分钟
- 数量关系：10-15分钟
- 常识判断：5-8分钟

### 资料分析单篇
- 阅读材料：1分钟
- 做题：每道1分钟
- 每篇5-6分钟

## 七、自查清单

### 每次做题后检查
- [ ] 是否识别出题型特征？
- [ ] 推理链是否完整？
- [ ] 是否用了速算技巧？
- [ ] 有没有掉进陷阱？
- [ ] 能否抽象出母题？
- [ ] 时间是否合理？

### 每周复盘
- [ ] 本周错题分类统计
- [ ] 薄弱考点是否专项训练
- [ ] 速算速度是否提升
- [ ] 正确率变化趋势
- [ ] 下周计划调整

## 关键 takeaway

1. 深度学习一道题胜过盲目刷十道题
2. 母题抽象是核心能力，做到"做一道会一类"
3. 错题必须分类归因，不能只对答案
4. 按考点学比按年份刷题效率高
5. 速度和正确率都要训练，不可偏废
