# 第一章：资料分析·增长

## 核心思想

增长是资料分析的基础，占比最大。核心是理清四个量的关系：现期量、基期量、增长率、增长量。

## 核心公式

### 基本概念
- **基期**：比较的基准时期（通常是"上年"）
- **现期**：当前时期（材料给出数据的时期）
- **增长率**：增长量÷基期量（百分数）
- **增长量**：现期量−基期量（绝对值）

### 核心公式表

| 求 | 已知 | 公式 |
|---|---|---|
| 基期量 | 现期量+增长率 | 基期=现期÷(1+增长率) |
| 现期量 | 基期量+增长率 | 现期=基期×(1+增长率) |
| 增长率 | 现期+基期 | 增长率=(现期−基期)÷基期 |
| 增长量 | 现期+基期 | 增长量=现期−基期 |
| 增长量 | 现期+增长率 | 增长量=现期÷(1+增长率)×增长率 |
| 增长量 | 基期+增长率 | 增长量=基期×增长率 |

## 高频考点

### 1. 基期量计算
- **问法特征**："上年/前一年……约为多少"
- **核心方法**：基期=现期÷(1+增长率)
- **速算**：
  - 截位直除（选项差距大时）
  - 百化分（增长率可化为特殊分数时）
  - 选项反代（选项×(1+增长率)≈现期）
- **陷阱**：
  - 增长率匹配错误（多个指标多个增长率时）
  - 时间口径错误（累计值vs当月值）
  - 正负增长方向判断（正增长基期<现期，负增长基期>现期）

### 2. 增长量计算
- **问法特征**："比上年增加/减少了多少"
- **核心方法**：增长量=现期÷(1+增长率)×增长率
- **速算（百化分）**：
  - 增长率r≈1/n，则增长量≈现期÷(n+1)
  - 例：增长率33.3%≈1/3，增长量≈现期÷4
- **增长量比较**：
  - 现期量大、增长率大 → 增长量大
  - 不满足时计算对比

### 3. 增长率计算与比较
- **问法特征**："同比增长了百分之几"
- **核心方法**：增长率=增长量÷基期
- **增长率比较**：
  - 直除法：比较增长量÷基期
  - 倍数法：现期÷基期的倍数越大，增长率越大
- **特殊**：
  - 增长率>100%时注意倍数表述
  - "多几倍"="是几倍"−1

### 4. 年均增长率
- **问法特征**："2016-2020年年均增长率"
- **公式**：末期=初期×(1+年均增长率)^n
- **方法**：
  - 代入特殊值验证
  - 居中代入（中间选项）
- **注意**：n为年份差（末期年份−初期年份）

### 5. 年均增长量
- **公式**：年均增长量=(末期−初期)÷年份差
- **注意**：五年规划期间年份差为5

### 6. 隔年（间隔）增长率
- **问法特征**：已知今年增长率r1、去年增长率r2，求今年比前年增长
- **公式**：r=r1+r2+r1×r2
- **速算**：r1×r2较小时可估算为r1+r2

### 7. 混合增长率
- **原理**：整体增长率介于各部分增长率之间
- **口诀**：整体居中，偏向基数大的
- **应用**：进口+出口=进出口，城镇+农村=全国

## 母题抽象

🧩 **基期量计算母题**：当题干出现"上年/基期……约为"且材料给出现期值与同比增速时，用基期=现期÷(1+增速)，先确认增速与指标对应，再截位直除或选项反代验证。

🧩 **增长量计算母题**：当题干出现"比上年增加多少"且材料给出现期值与增长率时，优先百化分（r≈1/n），增长量=现期÷(n+1)。

## 关键 takeaway

1. 四个量的关系是根本，公式要熟练
2. 基期量计算用除法，现期量用乘法
3. 增长量优先百化分，比硬算快
4. 先判断方向（正/负增长）排除选项，再计算
5. 注意增长率和具体指标的对应关系
