# 解题模式与题型识别

## 模式1：资料分析解题全流程

**场景**：拿到一篇资料分析材料
**步骤**：
1. 快速浏览材料（30秒，了解结构和时间）
2. 看题目，识别题型
3. 定位数据（文字材料找关键词，图表找行列）
4. 列式计算（优先速算）
5. 对照选项验证
6. 综合题最后做

## 模式2：基期量识别与计算

**题型特征**：
- 题干时间比材料时间早
- 出现"上年/去年/前一年"
- 问"约为多少"

**解题路径**：
1. 找现期值
2. 找对应增长率
3. 列式：现期÷(1+增长率)
4. 先判断方向（正增长基期<现期）
5. 截位直除或选项反代

## 模式3：增长量百化分

**题型特征**：
- 问"比上年增加/减少多少"
- 选项是绝对值

**解题路径**：
1. 找增长率
2. 化为特殊分数1/n
3. 增长量=现期÷(n+1)
4. 减少量=现期÷(n−1)

## 模式4：比重变化秒杀

**题型特征**：
- 问"比重比上年上升/下降几个百分点"
- 选项是百分点

**解题路径**：
1. 找部分增速a和整体增速b
2. 判断升降：a>b上升，a<b下降
3. 计算增速差|a−b|
4. 选小于|a−b|的选项
5. 通常直接秒杀

## 模式5：论证题解题

**场景**：加强/削弱题
**步骤**：
1. 找论点（因此/所以后）
2. 找论据
3. 判断话题是否一致
4. 加强：话题不一致→搭桥；话题一致→补充论据
5. 削弱：因果论点→因果倒置；有论据→拆桥；其他→他因
6. 排除无关选项

## 模式6：翻译推理

**题型特征**：题干有明显逻辑关联词
**步骤**：
1. 翻译：如果就前推后，只有才后推前
2. 串联：A→B→C
3. 看选项：
   - 肯前推肯后 ✓
   - 否后推否前 ✓
   - 否前、肯后 → 推不出
4. 且或用摩根公式

## 模式7：图形推理规律判断

**判断顺序**：
1. 元素组成相同 → 位置规律
2. 元素组成相似 → 样式规律
3. 元素组成不同：
   - 先看属性（对称/曲直/开闭）
   - 再看数量（点线面素角）
4. 空间类 → 相对面/相邻面方法

## 模式8：定义判断要件法

**步骤**：
1. 看提问（选是/选非）
2. 提取要件：主体、客体、方式、目的、条件
3. 选项逐一比对
4. 明显不符合的排除
5. 选匹配最多的

## 模式9：错题归因

**诊断流程**：
1. 不看答案重做
2. 重做对了 → 粗心/计算问题
3. 重做还错 → 知识盲区
4. 分类：
   - 知识盲区 → 学考点
   - 方法不熟 → 专项练
   - 计算失误 → 练速算
   - 审题错误 → 标记关键词
   - 陷阱入坑 → 总结陷阱
5. 找3道同类题巩固

## 题型快速识别表

| 题干关键词 | 题型 | 方法 |
|---|---|---|
| 上年/去年……约为 | 基期量 | 现期÷(1+r) |
| 比上年增加多少 | 增长量 | 百化分 |
| 增长百分之几 | 增长率 | 增量÷基期 |
| 占……比重 | 现期比重 | 部分÷整体 |
| 上年比重 | 基期比重 | 复杂公式 |
| 比重变化几个百分点 | 两期比重差 | 秒杀 |
| 平均每…… | 平均数 | 总量÷份数 |
| 是几倍 | 倍数 | A÷B |
| 多几倍 | 多几倍 | A÷B−1 |
| 如果……就 | 翻译推理 | 前推后 |
| 只有……才 | 翻译推理 | 后推前 |
| 最能加强 | 加强论证 | 搭桥/补论据 |
| 最能削弱 | 削弱论证 | 因果倒置/拆桥 |
| 几个人说几句话 | 真假推理 | 找矛盾 |
